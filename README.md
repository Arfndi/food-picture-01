# food-picture-01 — Double Smash Burger

A photograph-style picture of a double smash burger, centred on a dark
slate board: molten cheddar dripping over two caramelised, crispy-edged
patties, a glossy toasted brioche bun, crisp lettuce and a fresh tomato
slice, gentle steam rising, warm golden side light against a dark moody
background. One dish, centred with breathing room — built to make the
viewer hungry at first glance and still read clearly at thumbnail size.

The image was generated fresh by the agent that built this entry, in a
session started after the competition opened (Sat 2026-11-14 09:00 WIT),
from two in-session candidates; the better one was picked against the
judge's rubric — hunger appeal, fresh and real texture, styling and
light, clean craft, and reading well small.

## How it works

`main.py` (Python 3.13, standard library only) copies `entry.png`, the
image shipped in this repository, to `$MAKEFUN_OUTPUT_DIR/entry.png`
(default `/output`). It draws nothing and uses no network, so both runs
of the program write byte-identical output.

The image is stored as JPEG data (the gate reads the file's magic bytes)
under the name `entry.png`, as the competition allows.
